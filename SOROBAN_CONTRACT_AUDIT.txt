#### Function: `upload_record`

**EXACT SIGNATURE (from contract):**
```rust
pub fn upload_record(
    env: Env,
    patient: Address,
    ipfs_hash: Bytes,
    category: u32,
    file_size_kb: u32,
) -> Result<u64, ContractError>
```

**Parameter Breakdown:**
- `patient`: `Address` - patient wallet address (CALLER will authenticate via `patient.require_auth()`)
- `ipfs_hash`: `Bytes` - IPFS hash as raw bytes (NOT String)
- `category`: `u32` - category code (0=Prescription, 1=LabReport, 2=Scan, 3=Vaccination, 4=DischargeSummary, 5=Other)
- `file_size_kb`: `u32` - file size in kilobytes

**Returns:** `Result<u64, ContractError>` - record_id on success

**Authentication:** `patient.require_auth()` - Patient must sign the transaction

**Contract Validation:**
- Converts `category` from u32 to `RecordCategory` enum (fails if invalid)
- Increments record counter
- Creates `MedicalRecord` struct with all fields
- Stores record in persistent storage
- Adds record_id to patient_records list
- Emits `record_uploaded` event

**Event Emitted:**
```
Event: ("carevault", "rec_up") -> (record_id: u64, patient: Address, category: RecordCategory, ipfs_hash: Bytes)
```

## PART 4: AUTHENTICATION FLOW

All three functions require the **patient** to sign the transaction:

```rust
patient.require_auth();  // Contract check
```

**Frontend Implementation:**
- TransactionBuilder constructs the transaction
- `submitTransaction(xdr)` calls `freighter.signTransaction(xdr)`
- Freighter prompts user to sign
- Signed XDR is submitted to `sorobanServer.sendTransaction()`
- Transaction must be signed by the patient's Freighter wallet

**Current Status:** ✅ CORRECT - Patient address matches caller

## PART 5: TRANSACTION BUILDING FLOW

### Expected Sequence:

1. **Build** - TransactionBuilder creates unsigned transaction
2. **Simulate** - `sorobanServer.simulateTransaction(tx)` simulates on-chain
3. **Convert** - Convert simulated transaction to XDR string
4. **Sign** - Send XDR to Freighter for user signature
5. **Submit** - Submit signed XDR to blockchain
6. **Poll** - Poll for confirmation

### Current Frontend Implementation:

```typescript
const transaction = txBuilder.setTimeout(30).build();
const simResult = await sorobanServer.simulateTransaction(transaction);
if ((simResult as any).error) {
  throw new Error('Simulation failed...');
}
return transaction.toXDR();  // Return XDR for signing
```

**Status:** ✅ CORRECT FLOW
